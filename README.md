# Smart-City-Waste-Management-System
## Project Overview

The Smart Waste Management System is a role-based web application designed to provide an organized and efficient solution for managing waste collection and related operations. The system includes separate portals for Admin, Citizen, Driver, Collector, and Supervisor, with features such as complaint management, route and schedule management, staff management, collection records, reporting, and secure login.

## Technologies Used

- Oracle Database
- SQL
- PL/SQL
- Python Flask
- HTML
- CSS

## Key Database Concepts

The project implements several important database concepts, including:

- ERD Design
- Database Relationships
- Constraints
- Triggers
- Views
- Stored Procedures
- Data Integrity

## Project Learning

This project provided practical experience in database design, backend development, role-based system development, and solving real-world problems through a database-driven application.
